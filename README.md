# Slyzov-Privetka

Slyzov Privetka - Так называемый бот "Приветка", который реагирует на заявку в канал и отправляет человеку сообщение с просьбой подписаться на канал, для получения чего-либо. Такой способ используется для привлечения большего трафика.


## Возможности

### 🤖 Основной функционал
- **Автоматическая регистрация пользователей**: Отслеживает новых пользователей и дату их регистрации
- **Приветственные сообщения**: Отправляет настраиваемые приветственные сообщения с фото для новых пользователей
- **Управление каналами**: Добавление, удаление и отображение каналов для подписки
- **Кнопки подписки**: Отображает кнопки подписки на каналы в организованном виде (по 2 в ряд)

### 👨‍💻 Админ-панель
- **Статистика**: Просмотр общего количества пользователей, новых за сегодня и за неделю
- **Редактирование приветствия**: Изменение текста и фото приветственного сообщения
- **Управление каналами**: Добавление или удаление каналов из списка подписки
- **Рассылка**: Отправка сообщений всем зарегистрированным пользователям

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация пользователя и отображение приветствия с каналами для подписки |
| `/admin` | Открытие админ-панели (только для администраторов) |

## Кнопки админ-панели

| Кнопка | Функция |
|--------|---------|
| 📊 Статистика | Показать статистику пользователей |
| ✏️ Изменить приветствие | Изменить текст приветствия |
| 🖼️ Изменить фото приветствия | Изменить фото приветствия |
| ➕ Добавить канал | Добавить новый канал для подписки |
| ➖ Удалить канал | Удалить канал из списка подписки |
| 📋 Просмотреть каналы | Показать все добавленные каналы |
| 📢 Рассылка | Отправить сообщение всем пользователям |

## Установка

### Требования
- Python 3.7+
- Токен Telegram бота (получить у [@BotFather](https://t.me/BotFather))
- ID администраторов (можно узнать у [@userinfobot](https://t.me/userinfobot))

### Пошаговая установка

1. **Клонирование репозитория**
```bash
git clone <url-репозитория>
cd <папка-проекта>
```

2. **Установка зависимостей**
```bash
pip install -r requirements.txt
```

3. **Настройка бота**
   - Откройте файл `bot.py`
   - Замените `token="..."` на ваш токен от BotFather
   - Добавьте ID администраторов в список `ADMINS = []`
   ```python
   ADMINS = [123456789, 987654321]  # ID администраторов
   ```

4. **Запуск бота**
```bash
python bot.py
```

## Структура базы данных

### Таблица `users`
| Поле | Тип | Описание |
|------|-----|----------|
| telegram_id | INTEGER PRIMARY KEY | ID пользователя Telegram |
| balance | INTEGER DEFAULT 0 | Баланс (для будущих функций) |
| registration_date | TEXT DEFAULT CURRENT_TIMESTAMP | Дата регистрации |

### Таблица `welcome_message`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PRIMARY KEY | ID записи (всегда 1) |
| message_text | TEXT | Текст приветствия |
| photo_path | TEXT | Путь к фото приветствия |

### Таблица `channels`
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | ID канала |
| channel_name | TEXT | Название канала |
| channel_url | TEXT | Ссылка на канал |

## Использование

### Для обычных пользователей
1. Отправьте команду `/start` боту
2. Бот зарегистрирует вас и отправит приветственное сообщение
3. Нажмите на кнопки "Подписаться" для перехода в каналы

### Для администраторов
1. Отправьте команду `/admin`
2. Используйте кнопки для управления ботом:
   - **Изменить приветствие**: Отправьте новый текст
   - **Изменить фото**: Отправьте новое фото или напишите "удалить"
   - **Добавить канал**: Введите название, затем ссылку
   - **Удалить канал**: Выберите канал из списка
   - **Рассылка**: Напишите сообщение для отправки всем пользователям

## Решение проблем

### Бот не запускается
- Проверьте правильность токена бота
- Убедитесь, что установлены все зависимости
- Проверьте, что файл `db.db` создается в папке проекта

### Фото не отправляется
- Проверьте права доступа к папке проекта
- Убедитесь, что путь к фото корректен

### Админ-панель не открывается
- Проверьте, что ваш ID добавлен в список `ADMINS`
- Узнайте свой ID у бота @userinfobot

## Безопасность
